KitchenKart — Full-Stack E-commerce Store

A kitchen and home-appliance store built during Perficient's Global Graduate Training Program: a React 19 storefront and a Spring Boot / Java 21 REST API on PostgreSQL.

01. Overview

An appliance store with a React 19 storefront and a Spring Boot / Java 21 API on PostgreSQL, built as an individual training capstone at Perficient.

02. What I Built

  • Storefront with catalogue, cart, checkout, order tracking and an admin console (React + Redux Toolkit).
  • REST API in layers (controller → service → repository), with JWT access tokens and rotating refresh tokens.
  • Stock reservation that never oversells, and checkout that is safe against double-clicks.
  • Installation booking that activates the product's warranty once it's installed.

03. Bugs I Caught

  • Lockout that never locked: the failed-login counter was rolled back by the same error it recorded. Fixed and covered by a test.
  • Leaking stock: the job that releases abandoned carts never ran because scheduling wasn't enabled. Fixed and covered by a test.

04. How I Used AI

Built with AI coding assistants. I wrote the specs, reviewed every change before keeping it, and checked behaviour with tests and the running app — the bugs above were caught that way.
