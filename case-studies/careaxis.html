CareAxis — Hospital Management System

One system for a fictional 300-bed hospital, from registration to discharge: a Spring Boot transactional core, a FastAPI intelligence service and a React app for seven hospital roles.

01. Overview

A hospital management system for a 300-bed hospital and 7 staff roles: a Spring Boot core that keeps every record, a FastAPI service that scores risk, and a React front end.

02. What I Built

  • FastAPI scoring for ER triage, drug interactions and no-show risk.
  • A 2-second timeout, circuit breaker and safe fallback on every call to it — if it's down, ER patients default to the most urgent level.
  • Row-level locking so no clinic slot or bed is ever double-booked.
  • Care-team access rules, audited emergency access and an append-only audit log.

03. Bugs I Caught

  • My end-to-end audit of every user flow found defects that I fixed and covered with tests. Two examples:
  • Any doctor could discharge any patient — now only the patient's care team can.
  • Unlimited password guessing — now locked after 5 failed sign-ins in 15 minutes.
