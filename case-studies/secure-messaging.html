Secure Messaging via Steganography

A messaging tool that hides AES-encrypted messages inside ordinary image files — so the message travels as a normal-looking picture.

Security 2024 Cryptography
  • Python
  • AES
  • LSB Steganography
  • HTML / CSS

01. Overview

A tool that encrypts a message with AES and hides it inside an ordinary image, so it travels as a normal-looking picture.

02. What I Did

  • AES-encrypted messages before embedding them.
  • Hid the encrypted bytes in the image's least-significant bits (LSB) with no visible change.
  • Built the interface to hide and to extract-and-decrypt.
